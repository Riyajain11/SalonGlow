# Salon Appointment Booking App 💇‍♀️

A full-stack web application to book salon appointments online with OTP authentication.


## Tech Stack
**Frontend:** React + Vite + Tailwind CSS  
**Backend:** Node.js + Express.js + MongoDB  
**OTP Service:** Twilio / Fast2SMS (via phone number)

---

## Features
- User registration & login via OTP  
- Browse stylists and book appointments  
- View and manage upcoming bookings  
- Submit reviews and ratings after service  
- Admin panel (optional for future scope)

---

## How It Works
1. Enter your phone number to receive an OTP.  
2. Verify OTP to log in.  
3. Select stylist, date, and time.  
4. Confirm booking and view appointment history.
